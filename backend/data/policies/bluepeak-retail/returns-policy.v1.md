# Returns Policy

> Fictional policy for the CommerceOps AI demo (BluePeak Retail). Not a real company policy.

## Return window

Items can be returned within 14 days of delivery.

## Condition of returned items

Bedding and linen must be unwashed and in the original packaging. Made-to-order textiles
cannot be returned unless faulty.

## How to return an item

Register the return in the customer account and print the return form. Customers pay the
return shipping cost of 4.50 EUR, which is deducted from the refund.
