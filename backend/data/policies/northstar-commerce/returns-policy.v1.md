# Returns Policy

> Fictional policy for the CommerceOps AI demo (Northstar Commerce). Not a real company policy.

## Return window

Items can be returned within 30 days of delivery.

## Condition of returned items

Returned items must be unused, in their original packaging and with all accessories. Opened
earbuds and other in-ear audio products can only be returned if faulty.

## How to return an item

Start a return from the order page to receive a prepaid return label. Drop the parcel at any
ParcelPoint location. Return shipping is free for customers in the United States.
